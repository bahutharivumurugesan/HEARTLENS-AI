# ❤️ HEARTLENS-AI

## Intelligent Cardiovascular Risk Detection System

HEARTLENS-AI is an AI-inspired healthcare analytics project developed using Python.  
The system is designed to analyze critical cardiovascular health parameters and generate intelligent risk assessments for early heart disease awareness.

This project focuses on preventive healthcare by providing fast, accessible, and user-friendly cardiovascular analysis through an interactive console-based application.

---

# 🚀 Key Features

- Real-Time Cardiovascular Risk Analysis
- AI-Based Health Evaluation Logic
- Smart Patient Health Assessment
- Instant Risk Classification
- Personalized Health Recommendations
- Lightweight and Fast Execution
- Beginner-Friendly Yet Hackathon-Ready Architecture

---

# 🩺 Health Parameters Analyzed

The system evaluates the following patient health metrics:

- Age
- Heart Rate
- Blood Pressure
- Cholesterol Level
- Blood Sugar Level
